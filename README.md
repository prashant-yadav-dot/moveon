# 💜 MoveOn

### Your journey to healing, peace and a better tomorrow.

MoveOn is a supportive web application designed to help users navigate emotional healing after a difficult relationship or breakup.

## ✨ Features

- 🔐 Secure Email & Password Authentication
- 🏠 Personalized Home Dashboard
- 😊 Daily Mood Tracking
- 📔 Private Journal
- 🚫 No Contact Journey
- 🎯 Daily Healing Challenges
- 🧘 Calm & Relaxation Sessions
- 📚 Healing Lessons
- 📈 Personal Progress Tracking
- 💬 Support & Helpful Resources
- 👤 User Profile

## 🔥 Firebase Integration

MoveOn uses Firebase for:

- Firebase Authentication
- Realtime Database
- User-specific data storage
- Secure user data access

Each authenticated user can access only their own data.

## 🔒 Security

MoveOn uses:

- Firebase Authentication
- Realtime Database security rules
- Restricted Google/Firebase API key
- Authorized production domain
- HTTPS through Cloudflare
