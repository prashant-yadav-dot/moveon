MOVEON — EX ROLEPLAY SETUP

1. Upload all website files from this ZIP to your current MoveOn deployment.
2. The new page is: ex-roleplay.html
3. The frontend calls: /api/ex-roleplay
4. AI API keys must NOT be placed inside HTML/JavaScript.
5. Deploy ex-roleplay-worker.js as a Cloudflare Worker and route /api/ex-roleplay to it, OR merge its POST route into your existing Worker.
6. In the AI Worker, create a secret named OPENAI_API_KEY containing your OpenAI API key.
7. The worker uses the Responses API and the cost-sensitive GPT-5.6 Luna model.
8. The user can change the fictional ex's display name from the ⚙️ button.
9. Chat history is stored locally in the user's browser. The worker sends store:false to the model API.
10. For production, restrict CORS to your exact MoveOn domain instead of '*'.
